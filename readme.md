# Diaper Changing Bot for Bondage Club

## Prerequisites

- Node.js 18+

## Installation

1. Clone the repository

   ```bash
   git clone https://github.com/yourusername/abdl-bot.git
   cd abdl-bot
   ```

2. Install dependencies
   ```bash
   npm install
   ```
3. Create a .env file from .env.example

4. Start the bot
   ```bash
   npm start
   ```
